# V2 · Delprosjekt 5 — Kartet · Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tre syn på kartet (Nærhet, Nettverk, Kretser) med myke overganger, falming etter ferskhet, tagfilter, lagrede visninger og utledede relasjoner.

**Architecture:**
- **Ren geometri og logikk** ligger i `src/domain/` (ferskhet, filter, layouter, skall, bunting, interpolering), og alt er testet.
- **React Flow** er fortsatt eneste renderer:
  - Hvert syn er et sett posisjoner.
  - Kretser-kanter er en egen kanttype som tegner Bézier-banen fra kontrollpunkter.
  - Bakgrunner (ringer, omriss, gruppebuer) ligger i en `ViewportPortal`.
- **Visninger** lagres i en ny tabell (`MapView`). Siste syn og filter ligger i `localStorage`.

**Tech Stack:** Som før (Next 16, React 19, @xyflow/react 12, Prisma 7, zod, Vitest). Ingen nye avhengigheter.

**Spec:** `docs/superpowers/specs/2026-09-26-v2-5-kartet-design.md`

## Global Constraints

- Tokens, i18n, `requireUserId` og zod, `parseId`, `settle` og `refreshAll` som i delprosjekt 0–2.
- Ingen hex i komponenter. Taggfarger via `tagFill` og `tagStroke`, og SVG via `var(--…)`.
- Overganger: 450 ms `ease-in-out`. `prefers-reduced-motion` gir et umiddelbart bytte.
- Personer kan bare dras i Nettverk. Relasjoner kan lages ved å dra i alle syn.
- Nodens opasitet er `0,35 + 0,65 · ferskhet`, i alle syn.

## Review Focus

- **Personer uten tagg og uten logg:** de må få en plass i alle syn (egen «uten tagg»-sektor eller gruppe, ferskhet 0). *Test:* `nearness` og `circles` med tagg `null`.
- **Én person, eller ingen:** layoutene og skallene skal tåle 0, 1 og 2 personer uten NaN. *Test:* layout- og hull-testene.
- **Filter som skjuler alle:** kartet skal vise en tom tilstand som sier at filteret skjuler alle, med «Nullstill filter». Det skal ikke se ut som at kartet er tomt. *Test:* i komponenttesten.
- **Et lagret filter med en slettet tagg:** den ukjente tag-id-en ignoreres, og visningen virker fortsatt. *Test:* `mapFilter.normalize`.
- **Bytte syn midt i en overgang:** den nye overgangen starter fra der nodene står nå, uten hopp. *Test:* `interpolate`, og overgangs-hooken bruker gjeldende posisjoner som start.

```ts
// src/domain/freshness.test.ts
import { describe, it, expect } from 'vitest'
import { freshness } from './freshness'

const NOW = new Date('2026-09-26T12:00:00Z')
const weeksAgo = (w: number) => new Date(NOW.getTime() - w * 7 * 86_400_000)

describe('freshness', () => {
  it('er 1 innen halve kadensen', () => {
    expect(freshness(weeksAgo(1), 4, NOW)).toBe(1)
  })
  it('er 0 ved tre ganger kadensen og etter', () => {
    expect(freshness(weeksAgo(12), 4, NOW)).toBe(0)
    expect(freshness(weeksAgo(40), 4, NOW)).toBe(0)
  })
  it('faller lineært mellom', () => {
    // halv (2u) → 1, tre ganger (12u) → 0; 7u er midt imellom
    expect(freshness(weeksAgo(7), 4, NOW)).toBeCloseTo(0.5, 5)
  })
  it('er 0 uten kontakt', () => {
    expect(freshness(null, 4, NOW)).toBe(0)
  })
  it('bruker 26 uker for «aldri påminn»', () => {
    expect(freshness(weeksAgo(10), null, NOW)).toBe(1)
    expect(freshness(weeksAgo(78), null, NOW)).toBe(0)
  })
})
```

```ts
// src/domain/mapFilter.test.ts
import { describe, it, expect } from 'vitest'
import { DEFAULT_FILTER, normalize, isPersonVisible, isEdgeVisible, activeCount } from './mapFilter'

describe('mapFilter', () => {
  it('viser en person når minst én tagg er på', () => {
    const f = { ...DEFAULT_FILTER, hiddenTags: ['jobb'] }
    expect(isPersonVisible({ tagIds: ['jobb', 'klatring'] }, f)).toBe(true)
    expect(isPersonVisible({ tagIds: ['jobb'] }, f)).toBe(false)
  })
  it('personer uten tagg følger showUntagged', () => {
    expect(isPersonVisible({ tagIds: [] }, DEFAULT_FILTER)).toBe(true)
    expect(isPersonVisible({ tagIds: [] }, { ...DEFAULT_FILTER, showUntagged: false })).toBe(false)
  })
  it('skjuler kanter til skjulte personer og etter type', () => {
    const vis = new Set(['a', 'b'])
    expect(isEdgeVisible({ type: 'FRIEND', until: null }, vis, 'a', 'c', DEFAULT_FILTER)).toBe(false)
    expect(isEdgeVisible({ type: 'ROMANTIC', until: null }, vis, 'a', 'b', { ...DEFAULT_FILTER, hideRomanticEdges: true })).toBe(false)
    expect(isEdgeVisible({ type: 'FRIEND', until: new Date() }, vis, 'a', 'b', { ...DEFAULT_FILTER, showHistorical: false })).toBe(false)
  })
  it('normalize dropper ukjente tagger og rart innhold', () => {
    expect(normalize({ hiddenTags: ['slettet', 'jobb'], showUntagged: 'ja' }, ['jobb'])).toEqual({
      ...DEFAULT_FILTER,
      hiddenTags: ['jobb'],
    })
    expect(normalize(null, [])).toEqual(DEFAULT_FILTER)
  })
  it('teller aktive filtre', () => {
    expect(activeCount(DEFAULT_FILTER)).toBe(0)
    expect(activeCount({ ...DEFAULT_FILTER, hiddenTags: ['x', 'y'], hideRomanticEdges: true })).toBe(3)
  })
})
```

```ts
// src/domain/interpolate.test.ts
import { describe, it, expect } from 'vitest'
import { interpolate, easeInOut } from './interpolate'

describe('interpolate', () => {
  const from = new Map([['a', { x: 0, y: 0 }]])
  const to = new Map([['a', { x: 100, y: -50 }], ['b', { x: 10, y: 10 }]])
  it('går fra start til mål', () => {
    expect(interpolate(from, to, 0).get('a')).toEqual({ x: 0, y: 0 })
    expect(interpolate(from, to, 1).get('a')).toEqual({ x: 100, y: -50 })
    expect(interpolate(from, to, 0.5).get('a')).toEqual({ x: 50, y: -25 })
  })
  it('noder uten startpunkt står i mål med én gang', () => {
    expect(interpolate(from, to, 0.2).get('b')).toEqual({ x: 10, y: 10 })
  })
  it('easeInOut er 0 og 1 i endene og symmetrisk', () => {
    expect(easeInOut(0)).toBe(0)
    expect(easeInOut(1)).toBe(1)
    expect(easeInOut(0.5)).toBeCloseTo(0.5)
  })
})
```

### Task 2: Layouter, skall og bunting

**Files:** Create `src/domain/layouts/{nearness,circles,hulls,sectors}.ts`, med tester.

**Interfaces:**
- `type LayoutPerson = { id: string; name: string; groupId: string | null; freshness: number }`
- `type Group = { id: string | null; name: string }`, i rekkefølge. `null` er «uten tagg» og står alltid sist.
- `sectors(groups, persons): { groupId; start: number; end: number; members: string[] }[]`: vinkler i radianer, med start rett opp og retning med klokka. Tomme grupper hoppes over. Mellomrom på 0,06 rad mellom gruppene.
- `nearness(persons, groups, { rMin = 140, rMax = 520 }) → Map<id,{x,y}>`, med «deg» i (0,0). Også `NEARNESS_RINGS = [{ r, labelKey }]` for bakgrunnen.
- `circles(persons, groups, { r = 420 }) → { positions: Map; anchors: Map<groupId,{x,y}>; arcs: { groupId; name; start; end }[] }` og `bundlePath(from:{x,y}, to:{x,y}, fromAnchor, toAnchor, sameGroup, midAngle, r): string` (SVG-bane)
- `hulls(points: {x,y}[], pad = 40): string | null`: en lukket, glattet SVG-bane, eller `null` under 2 punkter. To punkter gir en kapsel (stadion).

- [ ] **Step 1: Tester (feiler).** Nøkkeltilfellene:
  - `sectors`: tre grupper med 2, 1 og 0 medlemmer gir to sektorer, der sektorstørrelsen er proporsjonal med medlemstallet, og gruppen «uten tagg» står sist.
  - `nearness`: ferskhet 1 gir radius `rMin`, ferskhet 0 gir `rMax`, og samme input gir samme output. Personer i samme gruppe har vinkler innenfor gruppens sektor.
  - `nearness` med én person og ingen grupper gir ingen NaN.
  - `circles`: alle står på radius r, og to kanter mellom gruppene A og B gir baner som bruker de samme ankerne (sjekk at `bundlePath` inneholder ankrenes koordinater).
  - `hulls`: 0 og 1 punkt gir `null`, 2 punkter gir en bane, og kvadratets hjørner ligger innenfor skallet.
- [ ] **Step 2–4:** Implementer til grønt.
  - `hulls` bruker Andrews monotone kjede-algoritme for det konvekse skallet.
  - Skallet forskyves utover med `pad` langs normalen i hvert hjørne, og hjørnene glattes med Catmull–Rom til kubiske Bézier-kurver.
